---

## How to Use This Vault

1. **New WIP item** - Use the `WIP-Item` template, save to `01-WIP/Active/`
2. **Session notes** - Use Daily Notes (Ctrl/Cmd+D) or the `Session-Note` template
3. **Share a resource** - Drop it in `02-Resources/References/`
4. **Record a decision** - Use the `Decision-Record` template in `04-Knowledge-Base/Architecture/`
5. **Move items through stages** - Active → Review → Archive

See [[Vault-Guide]] for detailed instructions.
