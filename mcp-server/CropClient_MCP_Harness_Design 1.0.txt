✅ Static injection (load-time only) ← your case

2. Scripts run once
3. Behavior is predictable

Important clarification (this is the boundary)

HTML harness
   Can use DOM
   Can have inline scripts
   Can be component-scoped
   Used for testing / visualization
   Can be run offline or online 

MCP
  Never runs this HTML
  Never sees the DOM
  Uses the ideas and logic, not the UI code
