API MCP SERVER - QUICK START
=============================

WHAT IT IS:
-----------
Second MCP server for CropManage API integration
Runs alongside Dashboard MCP Server
Port 3101 (Dashboard is 3100)

FILES:
------
server.js - MCP stdin/stdout protocol with 7 tools injected
api-component.js - CropManage API integration (622 lines, already tested)
package.json - Config
test-client.js - Tests all 7 tools

7 TOOLS:
--------
1. get_token - Authenticate with CropManage
2. get_ranches - Fetch ranch list (Grid 1)
3. get_plantings - Fetch planting list (Grid 2)
4. get_irrigation_details - Fetch irrigation data (Grid 4)
5. post_irrigation - Create new irrigation event
6. update_irrigation - Update existing event
7. batch_post_queue - Batch sync pending records

INSTALL:
--------
1. Unzip to: C:\AICode\crop-client-services\api-server\
2. Open CMD in that folder
3. Run: npm install
4. Done (no dependencies, installs instantly)

TEST:
-----
CMD: npm test
Should see: 5 tests pass, 7 tools listed
If all pass = ready to use

START SERVER:
-------------
Open CMD window
Navigate to: C:\AICode\crop-client-services\api-server\
Run: npm start
Leave window open
You'll see: "API MCP Server started - 7 tools ready"

TWO SERVERS RUNNING:
--------------------
CMD Window 1: Dashboard MCP Server (port 3100) - 4 CRUD tools
CMD Window 2: API MCP Server (port 3101) - 7 API tools

Both use stdin/stdout protocol
Both can run simultaneously
No port conflicts

FIRST REAL TEST:
----------------
With both servers running:
1. Use MCP client to call: get_token
2. Should authenticate with CropManage
3. Call: get_ranches
4. Should return ranch data
5. If both work = full system operational

UPDATING CODE:
--------------
If api-component.js needs changes:
1. Stop server (Ctrl+C in CMD)
2. Edit api-component.js
3. Save
4. Restart: npm start
5. Test: npm test (in new CMD)

Server automatically picks up changes on restart.

TROUBLESHOOTING:
----------------
"Module not found" = Check api-component.js is in same folder as server.js
"Port in use" = Different port than Dashboard (3101 vs 3100), should be fine
"Parse error" = Check JSON format in test requests
