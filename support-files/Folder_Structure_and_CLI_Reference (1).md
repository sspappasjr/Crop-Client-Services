## CLI Tools Reference

### 1. Pieces CLI
**Purpose:** Code snippet management and context tracking  
**Install:** `pip install pieces-cli`  
**Common Commands:**
```bash
pieces --version              # Check installation
pieces mcp setup             # Setup MCP for Claude Desktop (not used)
pieces                       # Interactive mode
```
**Our Use:** Code snippet management, context tracking

---

### 2. Git
**Purpose:** Version control and GitHub integration  
**Common Commands:**
```bash
git init                     # Initialize repository
git add .                    # Stage all changes
git commit -m "message"      # Commit changes
git push origin main         # Push to GitHub
git pull origin main         # Pull from GitHub
git status                   # Check status
```
**Our Use:** Version control, deploy to GitHub

---

### 3. npm (Node Package Manager)
**Purpose:** JavaScript package management  
**Common Commands:**
```bash
npm install                  # Install dependencies
npm start                    # Start application
npm run dev                  # Development mode
npm install <package>        # Install specific package
npm update                   # Update packages
```
**Our Use:** Manage Node.js dependencies, run server

---

### 4. MongoDB
**Purpose:** Database for irrigation data  
**Common Commands:**
```bash
mongod --dbpath ./data       # Start MongoDB server
mongo                        # Open MongoDB shell
mongosh                      # New MongoDB shell
```
**Our Use:** Store and manage agricultural data

---

### 5. MCP (Model Context Protocol)
**Purpose:** Connect LLM to data sources via natural language  
**Our Implementation:** Custom MCP server for CropClient  
**Commands:** Via natural language prompts (e.g., "read irrigation table")

## File Type Reference

### Configuration Files
- `*.json` - JSON configuration files
- `*-config.json` - Application-specific configs
- `package.json` - Node.js project configuration

### Documentation Files
- `*.md` - Markdown documentation
- `README.md` - Project overview
- `Napkin_*.md` - Design conversations

### Web Files
- `*.html` - Web pages and applications
- `*.css` - Stylesheets
- `*.js` - JavaScript files

### Data Files
- `irrigation.json` - Sample agricultural data
- `*.db` - Database files (if using SQLite)
